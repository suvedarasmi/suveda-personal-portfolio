# Suveda Rasmi S — Personal Portfolio

A responsive, single-page personal portfolio built with HTML5, CSS3 and vanilla JavaScript.

## Project structure

```text
profile-website/
├── index.html
├── css/
│   ├── theme.css
│   └── style.css
├── js/
│   └── main.js
├── images/
│   ├── hero/
│   ├── journey/
│   ├── interests/
│   ├── family/
│   └── hobbies/
├── .github/workflows/
├── .htmlhintrc
├── .gitignore
└── README.md
```

## Run locally

Open `index.html` in a browser. No package installation or build step is required.

## Themes

The design tokens are centralised in `css/theme.css`. The available theme values are `ivory` (default), `warm`, `dark`, and `sage`. Set `document.documentElement.dataset.theme` to one of these values to preview a theme.

## Before publishing

- Add the owner's portrait to `images/hero/` and replace the hero placeholder.
- Add selected, properly licensed photographs to the interests and hobbies sections.
- Replace placeholder social and email links with the owner's actual links.
- Confirm career dates, internship details and role descriptions.
- Add the GitHub Actions workflows required by the assignment.


## Personal sections

- **Things that make me, me:** music, movies and series, and food.
- **Beyond the workday:** travelling, exploring places, hosting and compering, and spending time with friends. Travel photography appears only in this second section to avoid repeating content.
